# TugasWeb-Pertemuan6-QuizApp

Tugas Rutin 6 — Pemrograman Web (3KOM40115): JavaScript DOM & Event Handling.

## Fitur
- 8 soal pilihan ganda (urutan diacak tiap putaran)
- Soal dirender dengan `createElement` + `textContent` (tanpa `innerHTML`)
- Event delegation: satu listener di `#options` untuk semua pilihan
- Skor otomatis di akhir kuis
- High score disimpan di LocalStorage
- Navigasi tanpa reload (SPA pattern)
- Feedback visual: benar = hijau, salah = merah (jawaban benar ikut disorot)
- Tombol ulangi kuis

## Bonus
Timer 15 detik per soal, progress bar, urutan soal acak, dark mode.

## Menjalankan
Buka `index.html` di browser.
